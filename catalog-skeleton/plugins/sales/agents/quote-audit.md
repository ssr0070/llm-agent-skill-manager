# 견적 감사 에이전트

## 호출 방법

이 에이전트는 **자동으로 발동하지 않는다.** `@sales:quote-audit` 으로 직접 지목해야 한다.

> 플러그인 에이전트의 `description`은 정보 표시용이며 자동 위임을 유발하지 않는다.
> 자연어로 자동 발동되어야 하는 기능은 **스킬**로 만든다 (PRD §6.3).

## 허용 도구

`Read`, `Grep`, `Glob` — **읽기 전용.**

`Bash`와 `Write`를 포함하지 않으므로 FR-304의 자동 승인 대상이다.
쓰기나 셸 실행이 필요해지면 **사람 승인 대상으로 전환**된다.

## 작업

1. 지정 기간의 견적 이력을 읽는다
2. 표준 할인율을 벗어난 건을 표시한다
3. 같은 고객사에 서로 다른 단가가 적용된 건을 찾는다
4. 검토 결과를 표로 요약한다 — **수정은 하지 않는다**
