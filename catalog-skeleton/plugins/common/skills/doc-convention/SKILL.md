# 사내 문서 작성 규칙

## 문서 머리말

모든 사내 문서는 다음 4줄로 시작한다.

| 항목 | 값 |
|---|---|
| 문서 상태 | Draft / Review / Approved |
| 작성일 | YYYY-MM-DD |
| 작성자 | 이름 |
| 공개 등급 | 전사 / 팀한정 / 대외비 |

## 용어 표기

- 외래어는 첫 등장 시 원어를 괄호로 병기한다 — 예: 카탈로그(catalog)
- 제품명은 공식 표기를 따른다
- 약어는 첫 등장 시 풀어 쓴다

## 제목 규칙

- 문서 제목은 명사구로. 문장으로 쓰지 않는다
- 절 제목은 번호를 붙인다

## 공개 등급 판단

- **대외비** — 단가, 마진, 인사 정보, 미공개 계약
- **팀한정** — 진행 중인 과제, 내부 평가
- **전사** — 나머지

> 이 스킬은 `common` 플러그인에 속하며 **Required 등급**으로 전사 배포된다. 개별 사용자가 제거할 수 없다.
