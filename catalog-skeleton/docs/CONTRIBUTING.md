# 스킬·에이전트 기여 가이드

## 1. 스킬인가 에이전트인가

**이 판단을 먼저 하십시오. 잘못 고르면 아무도 쓰지 못합니다.**

|  | 자동 발동 | 호출 방법 |
|---|---|---|
| **스킬** | ✅ 됨 | 자연어로 말하면 Claude가 알아서 씀 |
| **에이전트** | ❌ **안 됨** | `@플러그인:에이전트` 로 직접 지목해야 함 |

- **자동으로 떠야 하면 → 스킬.** 대부분의 업무 기능이 여기 해당합니다
- **오래 걸리는 자율 작업을 별도 컨텍스트에서 돌려야 하면 → 에이전트**

에이전트의 `description`은 설명용일 뿐 자동 위임을 유발하지 않습니다.

## 2. 만들기

```
plugins/<팀>/skills/<스킬이름>/
├── SKILL.md
└── evals/cases.jsonl
```

`SKILL.md` 머리말:

```yaml
---
name: 스킬이름            # 디렉터리명과 같아야 함
description: 무엇을 하는지 + 언제 쓰는지. 자동 발동의 유일한 근거. 1,536자 이내.
---
```

### 민감 데이터 규칙 — 가장 중요

> **단가·할인율·마진·심사 기준·내부 정책을 SKILL.md 본문에 넣지 마십시오.**
>
> 카탈로그 등재는 **전사 공개**를 의미합니다. 특정 팀에게만 보이게 하는 기능은
> 플랫폼에 존재하지 않습니다(Teams·Enterprise 모두). 민감한 값은 사내 API나
> MCP 서버 뒤에 두고, 스킬에는 **절차만** 적으십시오.

### description 쓰는 법

자동 발동은 오직 `description` 매칭으로 일어납니다.

- ❌ `견적서 관련 스킬` — 언제 쓰는지 알 수 없어 발동하지 않습니다
- ✅ `고객사 견적서 초안을 사내 표준 양식으로 작성한다. 사용자가 견적, 견적서, 단가 산출, 제안 금액 정리를 요청할 때 사용한다.`

스킬 목록 전체가 컨텍스트의 **1%**만 쓸 수 있습니다. 초과하면 **호출이 적은 스킬부터
description이 잘려** 매칭이 실패합니다. 짧고 구체적으로 쓰십시오.

### eval 케이스 (최소 3개)

```jsonl
{"type":"trigger","prompt":"발동해야 하는 요청","expect":"..."}
{"type":"non-trigger","prompt":"발동하면 안 되는 요청","expect":"..."}
{"type":"edge","prompt":"애매한 경계 사례","expect":"..."}
```

점수로 머지를 막지는 않습니다. 결과는 PR 코멘트로 남고, 월간 개선 배치의 자산이 됩니다.

## 3. 제출

```bash
/skill-submit <스킬이름>
```

브랜치 생성부터 PR 작성까지 자동입니다. PR 템플릿의 필수 항목을 채우십시오 —
**오너 / 배포 등급 / 목적 / 중복 검토 결과 / 데이터 등급**.

## 4. 심사

**CI 하드 게이트 2종** — 구조 린트, 보안 스캔. 통과해야 리뷰가 시작됩니다.

**승인 경로는 자동 판정됩니다.**

| 조건 | 결과 |
|---|---|
| `scripts/` · `hooks/` · `.mcp.json` · `bin/` 중 하나라도 있음 | **사람 승인 필요** |
| 에이전트 `tools`에 `Bash` 또는 `Write` | **사람 승인 필요** |
| 에이전트에 `tools` 미명시 | **사람 승인 필요** |
| 위 어느 것도 아님 (순수 문서형) | **자동 승인** |

문서형 스킬은 승인 대기 없이 머지됩니다. 관리자 3명은 **정말 봐야 할 것**에만 시간을 씁니다.

## 5. 배포 후

- 머지되면 조직 마켓플레이스가 동기화합니다
- 조직원 PC에는 **세션 시작 후 최대 10분 랜덤 지연**으로 반영됩니다
- **이미 실행 중인 세션에는 즉시 반영되지 않습니다** — 알림이 뜨면 `/reload-plugins`, 아니면 다음 세션에 자동 적용

## 6. 폐기

- **90일 동안 0회 호출**된 스킬은 분기 리뷰에서 오너에게 통보됩니다
- **2주 무응답** 시 deprecated 처리됩니다
- 되살리려면 사용 사례와 함께 PR을 다시 올리면 됩니다

## 7. 로컬에서 미리 검사하기

```bash
python3 scripts/lint_structure.py          # 구조 린트
python3 scripts/lint_structure.py --risk   # 승인 경로 확인
```
