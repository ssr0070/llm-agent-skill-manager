# 견적서 초안 작성

## 이 스킬이 하는 일

고객사 견적서를 사내 표준 구조로 작성한다. **단가와 할인 정책은 이 문서에 없다** — 사내 견적 API에서 조회한다.

## 데이터 취급 규칙 (FR-101 1번 규칙)

> ⚠️ **단가·할인율·마진율을 이 파일에 적지 않는다.**
> 카탈로그 등재는 전사 공개를 의미한다. 그룹별 노출 제한은 플랫폼에 존재하지 않는다.
> 민감한 수치는 전부 사내 견적 API 뒤에 둔다. 이 스킬에는 **절차만** 적는다.

## 절차

1. **입력 확인** — 고객사명, 품목, 수량, 납기, 특이 조건
2. **단가 조회** — 사내 견적 API에서 품목별 현재 단가를 가져온다 (이 스킬은 값을 저장하지 않는다)
3. **표준 항목 구성**
   - 품목 / 규격 / 수량 / 단가 / 금액
   - 소계 → 할인 → 공급가액 → 부가세 → 합계
4. **검토 필요 항목 표시** — 아래는 사람이 반드시 확인한다
   - 비표준 할인이 적용된 행
   - 납기가 표준보다 짧은 항목
   - 신규 고객사인 경우 여신 조건
5. **초안 출력** — 사내 견적서 양식에 맞춰 표로 제시하고, 4번 항목을 별도로 요약한다

## 하지 않는 것

- 최종 승인 — 초안일 뿐이다. 승인은 영업 책임자가 한다
- 고객에게 직접 발송
- 단가 협상 판단
